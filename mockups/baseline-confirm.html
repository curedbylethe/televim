A confirmation — and it names which side

A confirmation is a question about the whole screen, so it outranks every other thing the status line could say, and the label is CONFIRM whichever pane has the focus. The wording names which side the message is from, and says both, because Telegram deletes for both sides — a prompt implying otherwise would be a lie about what the next key does.

 CONFIRM  Delete your message from both sides? (y/n)

TestBackend assertions this frame is the reference for

  • The label is CONFIRM in mode-confirm, not mode-normal, whatever pane is focused.
  • The hint row is gone. A confirmation never shares the row with a hint, which is why the label budget is one number rather than a case per label.
  • y answers; n or Esc does not.
  • Ctrl-C does not ask. It is the way out when the program is wedged, and a terminal that is not answering cannot draw the question either.
  • A prompt over many messages carries counts — Delete 3 of your messages? (y/n) — and says how many were left out because they are placeholders.
