TestBackend assertions this frame is the reference for

    • Exactly one of the three pane corners carries border-focused, and it is the profile at (24, 0) — the same corner the conversation lights, which is what saying “it took the conversation's slot” means. the_conversation_is_where_it_was is the other half, and a change that lit the border in both states would say nothing.
    • not signed in in text, then the reason in text-dim. An empty panel is indistinguishable from a widget that has gone wrong, so the panel says what it is and why.
    • The reason wraps; it is not clipped. A bring-up failure carries a chain, so it is routinely longer than fifty-odd columns, and a reason cut at the panel's edge is a reason the reader cannot act on. The same wrap the bio uses.
    • There is no login action row on this frame. It lands with the login flow, and a row bound to nothing yet is a row that says so rather than a row that flashes.
