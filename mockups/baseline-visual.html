Two messages selected, in Visual mode

A selection spanning two or more messages is a set of messages, and it is drawn as a background on every row of every message it covers — decorations included, because the extent of the selection is the one thing on screen that is otherwise invisible. The cursor row inside it is still reverse video, because reverse video belongs to the cursor alone: a second user of it leaves the reader unable to tell which row the cursor is on. The count is in the title and the sentence is on the status line, because the title is one row wide.

TestBackend assertions this frame is the reference for

  • A selected message is styled whole: [you] and its text both sit on the selection background.
  • The cursor row is reverse video over the selection background, not instead of it.
  • The title carries · 2 selected, joined with ·.
  • The status line is the sentence, not the hint: a selection outranks a flash, because it is state the reader must not lose.
  • q and p are absent on purpose. q asks first, and p is unbound in Visual because replacing a selection with the reader's own text is a destructive reading of a key that looks additive.
